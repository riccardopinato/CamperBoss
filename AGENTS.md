# AGENTS.md

## Efficienza e riduzione del consumo

- Lavora sempre step by step.
- Ogni step deve riguardare una sola funzionalita, schermata o sezione coerente.
- Parti esclusivamente dalle cartelle e dai file necessari per completare lo step corrente.
- Leggi soltanto le dipendenze dirette strettamente necessarie.
- Non rileggere o analizzare ogni volta l'intero progetto o repository.
- Non effettuare audit globali, refactoring generali o modifiche estranee allo step.
- Ignora `build/`, `.dart_tool/`, file generati, file binari, archivi ZIP e documentazione non pertinente.
- Se ritieni indispensabile aprire altri file o ampliare l'ambito, spiegane prima il motivo.
- Riutilizza il codice e i componenti esistenti.
- Mantieni breve il riepilogo finale.
- Riduci al minimo letture, tool call, output e consumo di token senza compromettere la correttezza del codice.
